# Changelog

Releases of Yasuo Coach. Each entry describes what changed for someone using the app, not
what changed in the code.

## Unreleased

No public release yet. The repository currently carries documentation and the licence
only; the app is finished enough to use but has not cleared the checks its author set for
putting a binary in strangers' hands.

Two things stand between here and a first release:

- The packaged installer has not yet been confirmed reading a live game end to end. Until
  it is, a download would risk installing a coach that never speaks.
- How directly the coach phrases advice is under review for a public build. See
  [docs/BOUNDARY.md](docs/BOUNDARY.md).
